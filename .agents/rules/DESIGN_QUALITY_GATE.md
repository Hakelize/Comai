# DESIGN QUALITY GATE — NON-NEGOTIABLE

Design every interface in Comai as a real product designed by an experienced product designer, not as an AI-generated concept, Dribbble shot, or generic SaaS landing page.

The primary objective is:
SPECIFICITY > TRENDINESS
CLARITY > DECORATION
PRODUCT CHARACTER > “MODERN” AESTHETIC
FUNCTION > VISUAL EFFECTS

Do not optimize for what is statistically associated with “premium”, “AI”, “startup”, or “modern” web design.

Every visual decision must have a reason connected to:
- the product
- the user
- the information hierarchy
- the interaction
- the brand
- the content

If an element does not improve communication, navigation, hierarchy, comprehension, or interaction, remove it.

---

## 1. ABSOLUTELY AVOID “VIBE-CODED” VISUAL LANGUAGE

Do NOT automatically use:
- Purple/indigo gradients
- Generic AI blue/purple glow
- Aurora backgrounds
- Large radial light blooms
- Excessive neon
- Rainbow accents
- Sparkles or ✨ icons
- Emojis as interface icons
- Floating decorative shapes
- Random blobs
- Decorative grid backgrounds
- Excessive glassmorphism
- Frosted-glass everything
- Cards inside cards inside cards
- Giant icons with tiny labels
- Excessive rounded rectangles
- Pills used for everything
- Gradient text used as decoration
- Gradient borders everywhere
- “AI” visual clichés
- Fake dashboards
- Fake charts
- Fake testimonials
- Generic avatars
- Decorative status dots
- Random floating badges
- Excessive shadows
- Excessive blur
- Excessive hover effects
- Cursor-following effects
- Magnetic buttons
- Rotating cards
- Bounce animations
- Shimmer effects without functional purpose
- Lottie animations added only because the page feels empty

Do not add visual effects merely to make the interface appear more sophisticated.

---

## 2. DO NOT COPY THE DEFAULT SAAS DESIGN FORMULA

Avoid automatically producing generic marketing hero structures.
Choose the interface structure based on the actual product and user journey.
The interface should feel like it was designed specifically for Comai as a native on-device companion.

---

## 3. VISUAL SYSTEM

Use a restrained visual language:
- One primary brand color
- One secondary accent only when necessary
- Neutral background/surface colors
- Use accent color to communicate hierarchy or interaction
- Do not use color merely for decoration
- Prefer mostly neutral surfaces, controlled primary emphasis, and occasional warm emphasis for meaningful actions or states.

---

## 4. DEPTH WITHOUT GLASSMORPHISM DEPENDENCY

Glassmorphism may be used only where it improves hierarchy or establishes a meaningful layer.
Do NOT make every component translucent.
Prefer a clear surface hierarchy:
Background → Surface → Elevated surface → Interactive surface
Use subtle borders, restrained shadows, tonal contrast, spacing, and typography before using blur.

---

## 5. TYPOGRAPHY

Typography is the primary visual hierarchy.
Use:
- One primary typeface
- A strict type scale
- Deliberate font weights
- Consistent line heights
- Controlled letter spacing
Avoid oversized text, unnecessary uppercase labels, excessive bold text, and gradient text.

---

## 6. LAYOUT

Do not center everything. Use asymmetry when it improves hierarchy.
Use intentional alignment, consistent container width, predictable grid columns, meaningful whitespace, and clear grouping.
Use a strict spacing system based on 4px/8px increments: 8, 16, 24, 32, 48, 64, 96.

---

## 7. CARDS

Cards are not the default container for every piece of information.
Use a card only when the content represents an independent object, an actionable item, a distinct state, or a meaningful grouping.
Prefer whitespace and typography for simple content grouping. NEVER nest cards in cards.

---

## 8. BORDER RADIUS

Use a small, consistent radius system:
- 4px → controls / compact elements
- 8px → small components
- 12px → standard components
- 16px → major surfaces

---

## 9. ICONOGRAPHY

Use one consistent icon family.
Icons must have consistent stroke/fill treatment, consistent visual weight, and consistent size hierarchy.
Never use emojis as interface icons. Never add decorative sparkle icons.

---

## 10. MOTION

Animation must communicate state, hierarchy, feedback, continuity, or spatial relationships.
Avoid bounce, excessive spring physics, floating, and shaking.

---

## 11. COPY & REAL PRODUCT BEHAVIOR

- Never generate generic startup copy or slogans.
- Copy must describe the actual product and actual user benefit.
- Never invent customers, statistics, or mock reviews.
- Every visible interactive element must work.
- Provide deliberate Loading → Success → Error → Empty states.

---

## FINAL RULE

Do not try to make the interface look “premium”. Make it look considered, specific, coherent, useful, credible, calm, and product-specific.
